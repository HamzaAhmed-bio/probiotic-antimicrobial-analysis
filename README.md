# probiotic-antimicrobial-analysis

Undergraduate capstone project at Ain Shams University, 2025, evaluating the antimicrobial activity of probiotic bacterial strains.

## Status

This repository documents the project. The analysis scripts and figures are not published here.

## Background

Probiotic strains can inhibit the growth of pathogenic bacteria. This project tested a panel of strains for antimicrobial activity in the lab and looked for corresponding features in their genomic sequences.

## Methods

Laboratory: bacterial culture, growth measurement, and inhibition-zone assays across the strain panel.

Sequence analysis: annotation of bacterial genomic sequences to identify genes associated with antimicrobial activity.

Statistics: comparison of antimicrobial activity across strains.
