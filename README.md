# probiotic-antimicrobial-analysis

Undergraduate capstone project. Ain Shams University, 2025.

The project evaluated the antimicrobial activity of a panel of probiotic bacterial strains against pathogenic bacteria, combining laboratory assay data with analysis of the strains' genomic sequences.

Laboratory work covered bacterial culture, growth measurement, and inhibition-zone assays across the strain panel. Sequence analysis annotated bacterial genomes to identify genes associated with antimicrobial activity. Activity was then compared statistically across strains.
